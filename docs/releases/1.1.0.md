# W3x2lni Reforged 1.1

This release refreshes the Windows conversion interface, adds independent JASS
verification and updates the verified MPQ compression runtime.

## Download

Download `w3x2lni-reforged-1.1.0-windows-x86.zip` from this release's assets.
Extract the entire ZIP into a new folder and launch `w3x2lni.exe`. Use `w2l.exe`
for command-line conversion. The included `warcraft-current` dataset is selected.
GitHub's source-code archives are for development; use the portable ZIP to run
the application.

## Conversion interface

Choose **To LNI**, **To OBJ** or **To SLK** from a clearer format-selection screen.
Existing conversion options, including JASS optimization and editor-only file
removal for SLK, remain available.

The high-contrast dark interface uses readable light text, native checkboxes and
Space/Enter keyboard activation. **Change format** returns to format selection.
Controls are disabled while conversion runs to prevent accidental changes.
Conversion reports remain selectable and copyable. Review the SLK
settings before starting: removing editor-only files or unreferenced objects can
make the result unsuitable for further editing. Use OBJ or LNI for editable work.

## Independent, report-only JASS verification

The pinned pjass helper checks the actual JASS script against common.j and
blizzard.j from the selected Warcraft dataset. Input and final converted scripts
are checked separately. Results include Passed, Failed, Unavailable and Skipped;
Lua maps are skipped. Map-supplied declaration replacements get a separate result.
Failures are visible but do not block output, repair scripts or alter conversion
exit status. A failed, suppressed or unavailable check is never labeled Passed.
Syntax/declaration checking does not establish gameplay correctness.

## Native dependency provenance

The new Actions path builds Windows x86 Unicode StormLib 9.40 against static zlib
1.3.2 from exact pinned source commits. Its ABI/storage probe, settings, compiler
and hashes accompany the artifact. Only that verified StormLib DLL may replace
the upstream file. The other 21 upstream native files retain byte verification.
The pinned upstream pjass release is an added helper with its own checksum.
BUILD_INFO.json distinguishes these origins; NATIVE_BUILD.json and NATIVE_ABI.json
retain build and ABI evidence. No binaries or release artifacts belong in Git.

CascLib and the remaining original runtime are retained. Its source still uses
its own older zlib copy; updating it needs a separate real-game extraction check.

## Compatibility notes

- Automated checks cover compatibility fixtures, native Windows conversions,
  JASS verification, archive preservation and failure recovery. These checks
  cover representative fixtures rather than every custom map.
- pjass validates JASS syntax and declarations; its result does not establish
  gameplay correctness. Lua maps retain their scripts and skip pjass.
- Existing SLK optimization settings remain unchanged. Review object pruning,
  model compression and editor-only file removal before conversion.
- Test your converted maps in the intended editor and game version. Native CASC
  extraction and the retained GUI runtime remain separate compatibility areas.
