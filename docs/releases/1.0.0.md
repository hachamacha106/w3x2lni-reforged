# W3x2lni Reforged 1.0

The first release of **W3x2lni Reforged**, a community fork of
[sumneko/w3x2lni](https://github.com/sumneko/w3x2lni), brings the original LNI,
OBJ, and SLK workflows forward for modern Warcraft III maps.

## Download

Download **`w3x2lni-reforged-1.0.0-windows-x86.zip`** from this release's assets.
Extract the entire ZIP into a new folder and run **`w3x2lni.exe`**. The command
line executable is **`w2l.exe`**. The included `warcraft-current` dataset is
already selected.

The portable ZIP contains the application and its runtime. GitHub's **Source
code** archives are for development.

## Highlights

### Current map and object data

- W3I format 39 support, including corrected fog/weather order, fog heights,
  sky settings, minimap alpha colors, and loading-screen race HUD values.
- Descriptive `w3i.ini` names for graphics modes, game-data version,
  start-location priority masks, and formerly numbered unknown map flags.
- Version 3 object records, binary skin sidecars, extended ability levels,
  current SLK schemas, skin localization, and native text-profile handling.
- Fixes for GUI triggers, placement references, imports, current native map
  files, Lua script preservation, and string-table IDs.

### Better reports

- Resize or maximize the main window.
- Read long messages with wrapping and vertical scrolling.
- Select text and press **Ctrl+C**, use **Ctrl+A** to select the displayed
  report, or click **Copy all** to copy the complete loaded log.
- See complete crash messages when the bundled Lua runtime inserts NUL bytes
  into its error output.

### Release verification

The release process checks every ZIP member against its checksum and intended
source bytes. It runs the 14 compatibility test groups from the extracted
candidate, including eight conversion paths for a current-editor sample and
six rebuilt MPQ archives. The GitHub release draft is gated on an additional
Windows CLI smoke test of the exact packaged native runtime.

`BUILD_INFO.json`, `TEST_RESULTS.txt`, `PACKAGE_VERIFICATION.json`, and
`CHECKSUMS.sha256` in the ZIP record the build and package validation. The release
also provides an external ZIP checksum and `WINDOWS_SMOKE.json` from the Windows
job.

## Compatibility notes

The included map fixture was saved by **Warcraft III 3.0.1.24342** with **W3I
format 39**. The raw dataset is complete for the supplied base export, but its
exact extraction build and locale were not independently confirmed. Separate
custom-balance or graphics-specific data overlays were not included.

The native Windows executables and DLLs are unchanged from the official upstream
**2.7.3** release; the converter and UI updates are in the scripts. Automated
Windows CLI checks do not exercise the GUI clipboard, game-storage extraction,
World Editor, or actual gameplay. Check representative maps in your editor and
game as part of your normal release testing.

JASS optimization and obfuscation remain available. Lua scripts are preserved;
there is no Lua script optimizer or new HD model compressor. Unknown object
data and flags remain preserved. Where references cannot be analyzed reliably,
unused-object removal retains objects and explains the reason in the report.

LNI projects from previews 4 and 5 already use the current W3I field names. If
you used an earlier testing preview, re-export from the original map to obtain
the new names and matching locale dictionary.
