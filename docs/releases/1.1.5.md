# W3x2lni Reforged 1.1.5

Released 2026-10-10.

This maintenance release fixes JASS obfuscation and clarifies object-ID warnings
without changing the LNI, OBJ or SLK conversion defaults.

## Download

Download `w3x2lni-reforged-1.1.5-windows-x86.zip` from this release's assets.
Extract the entire ZIP into a new folder and launch `w3x2lni.exe`. Use `w2l.exe`
for command-line conversion. The included `warcraft-current` dataset is selected.
Use the portable ZIP to run the application; GitHub's source-code archives are
for development.

## Confuse scripts fixes

The advanced **Confuse scripts** option, used with **Optimize JASS**, now:

- Reserves original function, global and type names so generated identifiers
  cannot duplicate declarations retained for string-based calls or variable events.
- Preserves callback names and original `ExecuteFunc` string prefixes when runtime
  suffixes can reach the same function through overlapping routes.
- Follows callbacks reached through other dynamic dispatchers before removing
  unreferenced functions. Fully dynamic calls retain possible callback names.
- Resets optimizer and serializer state for every operation, preventing earlier
  conversions from affecting later scripts or global initializers.
- Deduplicates custom alphabets and skips identifier renaming when an alphabet has
  too few distinct characters or letters, while reporting the invalid setting.

Conservative callback-name retention can produce less obfuscated output. It
preserves runtime routing rather than rewriting names that cannot be resolved
safely. JASS obfuscation remains optional; Lua map scripts are preserved.

## Clearer object-ID warnings

Warnings now distinguish case-only SLK/TXT storage collisions from profile keys
shared by different object types. Case-distinct rawcodes keep their original IDs;
retained objects use binary object data when SLK/TXT cannot store them separately.
Conflicting TXT fields also retain their binary fallback. Optional removal of
unreferenced objects keeps its existing behavior.

These warnings describe conversion storage limitations. They do not require
renaming otherwise distinct object IDs and do not, by themselves, establish that
a map is corrupted.

## Verification and compatibility

Targeted regressions cover duplicate identifiers, overlapping and transitive
callbacks, repeated optimizer invocations and valid/invalid custom alphabets.
The Windows regression action checks original and transformed scripts with real
pjass against the current, 1.27.1 and 1.24.4 declaration datasets. Object-data tests
cover exact IDs and distinct values through LNI, OBJ and SLK conversion.

The maintainer reported that both **Confuse scripts off** and **Confuse scripts on**
outputs from the local preview were playable on their tested map. The original
map from the corruption report was unavailable, so its exact hosting failure was
not reproduced.

pjass remains report-only: failures stay visible without blocking conversion or
changing its exit status. A pjass pass checks syntax and declarations, not dynamic
callback behavior or gameplay. Test converted maps in your intended Warcraft III
version. Keep OBJ or LNI as the editable source; SLK settings can remove editor-only
information.
